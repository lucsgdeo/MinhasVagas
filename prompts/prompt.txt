   `[{"id": "...", "name": "...", "workplaceType": "...", "jobUrl": "...", "publishedDate": "...", "topic": "...", "data_formatada_br": "..."}]`
3. A limpeza de 7 dias também deve expurgar vagas antigas de `vagas_recentes.json`.
4. Garanta que o `main.py` salve/atualize o `vagas_recentes.json` junto com o `vagas_vistas.json`.

### TAREFA 2: Frontend no GitHub Pages (`index.html`)

Crie o arquivo `index.html` na raiz do projeto com layout moderno e responsivo usando Tailwind CSS:

1. **Abas Superiores por Período:**
   - [Aba 1] "Últimas 24 Horas" (Filtra vagas publicadas nas últimas 24h).
   - [Aba 2] "Últimos 7 Dias" (Exibe todas as vagas registradas em `vagas_recentes.json`).

2. **Filtros Rápidos por Botões (Pills Clicáveis):**
   - Fileira de botões clicáveis no topo da lista para filtragem instantânea:
     - `Todas`
     - `100% Remoto`
     - `Presencial`
     - `Suporte`
     - `TI`
     - `Infraestrutura`
     - `Service Desk`
     - `Júnior`
     - `Help Desk`
   - Campo de busca textual (input) para pesquisar títulos de vagas em tempo real.

3. **Grid de Vagas:**
   - Cards com: Título, Badge de Modalidade (Remoto/Presencial), Tag da Área/Tópico, Data de Publicação e Botão "Candidatar-se" (link externo Gupy).

4. **Botão de Sincronização Manual (GitHub Actions):**
   - Botão "🔄 Sincronizar Agora" no header.
   - Ao clicar, solicita o GitHub Personal Access Token (PAT) via modal/prompt e dispara uma requisição `POST` para a API do GitHub (`/actions/workflows/main.yml/dispatches` com `{"ref": "main"}`).
   - Exibe feedback de sucesso/erro ao disparar.
